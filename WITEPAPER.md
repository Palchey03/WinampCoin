# WinampCoin (WAMP) Whitepaper

## 1. Project Overview

WinampCoin (WAMP) is an independent community-oriented BEP-20 token deployed on the BNB Smart Chain.

The project focuses on transparency, community participation, decentralized trading, and open development.

WinampCoin is not affiliated with, endorsed by, or sponsored by Winamp or any other third-party brand.

## 2. Vision and Purpose

The purpose of WinampCoin is to create a simple and transparent community token with publicly verifiable blockchain information.

The project aims to build an initial community, develop its online presence, and explore community-oriented uses for WAMP over time.

No investment return, price appreciation, or financial outcome is guaranteed.

## 3. Token Information

- Token Name: WinampCoin
- Symbol: WAMP
- Blockchain: BNB Smart Chain
- Token Standard: BEP-20
- Decimals: 18
- Total Supply: 1,000,000,000 WAMP
- Maximum Supply: 1,000,000,000 WAMP
- Contract Address: 0xbEe5F34177ED9a94C0c086B152e05b35cA304d2D

The token has a fixed maximum supply of 1,000,000,000 WAMP.

The smart contract does not contain a public function allowing additional WAMP tokens to be minted after deployment.

## 4. Token Distribution

At deployment, the fixed supply of 1,000,000,000 WAMP was minted to the deployer address according to the smart contract constructor.

A portion of the supply was subsequently used to establish WAMP/BNB liquidity on PancakeSwap.

The project does not claim that every token should automatically be considered circulating supply for market-ranking purposes. Circulating supply may depend on the methodology used by individual market-data providers.

## 5. Smart Contract

WinampCoin uses the OpenZeppelin ERC-20 implementation and is deployed as a BEP-20 compatible token on BNB Smart Chain.

The smart contract source code has been publicly verified on BscScan.

Contract Address:

0xbEe5F34177ED9a94C0c086B152e05b35cA304d2D

The fixed supply and absence of an additional minting mechanism are intended to provide predictable and transparent token supply.
